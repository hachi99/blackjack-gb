# Blackjack

A simple Blackjack game built with HTML, CSS and JavaScript.
This was made so I can play blackjack on my phone without downloading any apps with ads

## Features

- Blackjack rules
- Responsive interface
- Progressive Web App (PWA)
- Offline support

## Technologies

- HTML
- CSS
- JavaScript
